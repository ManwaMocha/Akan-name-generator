# Akan Name Generator

## 📌 Project Description

The Akan Name Generator is a web application that calculates the day of the week a user was born and assigns them an Akan name based on Ghanaian cultural traditions.

In Akan culture, children are named according to the day of the week they are born. Each day corresponds to a specific male and female name, reflecting identity and heritage.
